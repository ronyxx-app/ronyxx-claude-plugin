# Stock to reorder

Ask Ronyxx with the `ask` tool, one question at a time:

1. Which products are running low?
2. Which products will run out within 30 days at the recent rate?
3. What do we have on order from suppliers, per product?
4. Which receipts from suppliers are late?

Show each answer under its own heading, exactly as Ronyxx gave it.

Rules:
- Never change, round, add up or combine Ronyxx's figures, and never work out quantities to order yourself. If the person asks how much to order of a product, ask Ronyxx about that product's stock, days of stock and what is on order, and show those answers.
- If a product appears in more than one answer, you may say so in words, quoting each figure exactly as Ronyxx gave it.
- If Ronyxx can't answer one of them, say so in one line and go on.
